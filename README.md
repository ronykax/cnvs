# cnvs

an infinite 2D space where i pin sticky notes anywhere i want, like pinning paper notes to a physical corkboard.

notes have free-form (x, y) position, a color, and markdown content. no folders, no hierarchy, no forced structure — organization comes from where the user physically places each note on the board.

the core interaction is: add a note, pick a color for it, drag it anywhere, done.
